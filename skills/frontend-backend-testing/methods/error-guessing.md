# 测试设计方法 · 错误推测法

## 概念

凭经验/Bug 库反推"程序员容易犯的错"，针对性构造用例。配合 `checklists/*-common-bugs.md`。

## 经验清单

### 数字
- 0 / 负数 / 极大值 / 精度丢失（0.1 + 0.2）/ NaN / Infinity
- 整数溢出（int32 / int64）
- 浮点 vs Decimal（金额）

### 字符串
- 空 / 空格 / 只有空格 / 首尾空格
- 中文 / Emoji / 控制字符 / 零宽字符
- 极长字符串 / 单字符
- SQL/XSS payload

### 时间
- 跨年 / 跨月 / 闰年 / 跨时区
- 1970-01-01 / 2038-01-19
- 夏令时切换瞬间

### 并发
- 双击 / 快速点击
- 两端同时操作同一资源
- 同账号多端登录

### 网络
- 离线 / 弱网 / 高延迟 / 中途断开 / 重连

### 数据
- 空数组 / 单项 / 上千项
- 嵌套缺失字段
- null vs undefined vs 缺字段

### 权限
- 直接 URL 访问
- 修改 ID 横向越权
- 调用低权限不应有的接口

## 适用场景

- 兜底测试，补 Checklist 之外的洞
- 与 Bug 模式库一起用
