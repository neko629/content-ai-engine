# 测试设计方法 · 判定表

## 概念

多个条件组合决定输出时，用判定表穷举所有条件组合。

## 步骤

1. 列出所有条件（输入或状态）
2. 列出所有动作（输出或副作用）
3. 构造判定表：行 = 用例，列 = 条件 + 动作
4. 简化：合并等效列、删除不可能组合

## 示例：折扣计算

条件：会员等级 ∈ {普通, VIP}、金额 ≥ 100、节日 ∈ {是, 否}

| # | 会员 | 金额≥100 | 节日 | 折扣 |
|---|---|---|---|---|
| 1 | 普通 | ✗ | ✗ | 0% |
| 2 | 普通 | ✓ | ✗ | 5% |
| 3 | 普通 | ✗ | ✓ | 5% |
| 4 | 普通 | ✓ | ✓ | 10% |
| 5 | VIP | ✗ | ✗ | 10% |
| 6 | VIP | ✓ | ✗ | 15% |
| 7 | VIP | ✗ | ✓ | 15% |
| 8 | VIP | ✓ | ✓ | 20% |

每行 = 1 个测试用例。

## 适用场景

- 业务规则复杂、多条件组合
- 与正交组合配合，大表用正交压缩
