# 测试设计方法 · 边界值分析

## 概念

Bug 高密度区在边界。对每个边界取 6 个值：**min-1 / min / min+1 / max-1 / max / max+1**。

## 步骤

1. 找出所有数值/长度/数量边界
2. 对每个边界生成 6 个用例
3. 注意"隐性边界"：数组长度 0、空字符串、单字符、第一项、最后一项

## 示例：用户名长度 4–20 字符

| 用例 | 值 | 预期 |
|---|---|---|
| 长度 3（min-1） | "abc" | 校验失败 |
| 长度 4（min） | "abcd" | 通过 |
| 长度 5（min+1） | "abcde" | 通过 |
| 长度 19（max-1） | 19 字符 | 通过 |
| 长度 20（max） | 20 字符 | 通过 |
| 长度 21（max+1） | 21 字符 | 校验失败 |

## 常见隐性边界

- 数字：0 / 1 / -1 / 最大值 / 最小值 / 最大值+1 溢出
- 时间：1970-01-01 / 2038-01-19（Y2K38）/ 闰年 2-29 / 跨年
- 列表：空 / 1 个 / 满页 / 满页+1
- 文件：0B / 1B / 限值 / 限值+1B
- 分页：第 0 页 / 第 1 页 / 末页 / 末页+1
