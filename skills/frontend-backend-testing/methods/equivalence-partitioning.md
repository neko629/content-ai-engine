# 测试设计方法 · 等价类划分

## 概念

把输入划分为若干个等价类，每个类中任取一个值代表整个类。  
分两种：**有效等价类**（合法输入）+ **无效等价类**（非法输入）。

## 步骤

1. 列出输入字段的所有约束（类型、范围、格式、必填）
2. 按约束划分有效类与无效类
3. 每类取 1 个代表值
4. 有效类可合并测试，无效类必须独立测试（避免一次报多个错被掩盖）

## 示例：年龄字段（整数，0–150）

| 等价类 | 取值代表 | 类型 |
|---|---|---|
| 有效：婴幼儿 0–3 | 1 | 有效 |
| 有效：未成年 4–17 | 10 | 有效 |
| 有效：成年 18–59 | 30 | 有效 |
| 有效：老年 60–150 | 80 | 有效 |
| 无效：负数 | -1 | 无效 |
| 无效：超上限 | 151 | 无效 |
| 无效：非整数 | 25.5 | 无效 |
| 无效：非数字 | "abc" | 无效 |
| 无效：空 | "" | 无效 |

## 适用场景

- 输入域可清晰划分
- 与边界值分析配合使用（先等价类再加边界）
