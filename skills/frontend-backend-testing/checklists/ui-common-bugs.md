# UI 常见 Bug 模式库

走查时按此列表逐项核对，避免漏测。

## 色彩 / Token
- [ ] 主题色色值偏差（含大小写）
- [ ] 状态色（成功/警告/错误）不一致
- [ ] 暗色模式硬编码白色背景
- [ ] 半透明色叠加后实际色与稿不同

## 间距 / 网格
- [ ] 出现非 4/8px 倍数（13/19/27px 等）
- [ ] 内边距左右不对称
- [ ] 上下间距随内容变化（缺固定 spacing）
- [ ] 移动端边距过小（< 16）

## 字体 / 字号
- [ ] 字号非设计 token 中的值
- [ ] 移动端字号 < 12px
- [ ] 行高与字号比例失衡
- [ ] 设计字体未加载时降级字体过丑

## 按钮 / 输入
- [ ] 按钮高度非整数
- [ ] Loading 态缺失
- [ ] Disabled 态视觉与 Active 态相近
- [ ] Hover/Focus 态丢失
- [ ] 移动端按钮 < 44×44
- [ ] 输入框聚焦边框颜色与设计不符
- [ ] 错误状态边框 + 错误提示位置错

## 状态
- [ ] 空状态缺失（列表无数据空白）
- [ ] 加载态缺失（页面闪现"无数据"再加载出来）
- [ ] 错误态缺失（接口失败页面崩白）
- [ ] 无更多 / 加载更多缺失

## 文字 / 排版
- [ ] 长文本溢出（不省略、不换行）
- [ ] 数字与中文不对齐
- [ ] 标点占位与英文混用
- [ ] 多语言字符宽度差异未处理

## 响应式
- [ ] 断点处出现错位
- [ ] 横屏布局未做
- [ ] iOS 软键盘弹起遮挡输入框
- [ ] 浏览器缩放后溢出

## 图片 / 图标
- [ ] DPR 2/3x 模糊
- [ ] 加载失败无占位
- [ ] 用了位图本应用 SVG
- [ ] 图标尺寸非 token 值
