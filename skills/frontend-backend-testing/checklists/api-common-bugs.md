# 接口常见 Bug 模式库

## 契约
- [ ] 文档字段名 ≠ 实际字段名（camelCase vs snake_case）
- [ ] 文档必填，实际可选（或反之）
- [ ] 文档返回数组，实际返回对象
- [ ] 嵌套结构与文档不符
- [ ] 字段类型不一致（string vs number）
- [ ] 时间格式混乱（毫秒/秒/ISO 字符串混用）
- [ ] ID 字段类型不一致

## 状态码
- [ ] 业务失败仍 200（body.code 表示失败）
- [ ] 鉴权失败返 500 不返 401
- [ ] 越权返 404 假装不存在
- [ ] 资源不存在返 200 + null
- [ ] 重复创建返 200 不返 409

## 错误响应
- [ ] 成功 / 失败响应结构不统一
- [ ] 错误信息是代码不是人话
- [ ] 错误信息泄露内部栈或 SQL

## 性能
- [ ] 无分页返回大数据
- [ ] N+1 查询
- [ ] 关键接口 P95 > 阈值
- [ ] 无超时设置

## 安全
- [ ] 敏感字段返回明文（手机/身份证/密码 hash）
- [ ] 越权（横向/纵向）
- [ ] 无限流
- [ ] 非 HTTPS

## 幂等 / 并发
- [ ] 非幂等接口无幂等键
- [ ] 重复点击产生重复记录
- [ ] 并发更新无锁

## 其他
- [ ] CORS 配置过松
- [ ] OPTIONS 预检失败
- [ ] 大对象响应 > 1MB 未分块
