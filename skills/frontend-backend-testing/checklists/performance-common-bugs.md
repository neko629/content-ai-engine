# 性能常见 Bug 模式库

## 前端
- [ ] 首屏 LCP > 2.5s
- [ ] 包体未拆分（首屏加载所有路由代码）
- [ ] 图片未压缩 / 未懒加载
- [ ] 字体加载阻塞渲染（FOIT）
- [ ] 长列表无虚拟滚动
- [ ] 频繁 re-render
- [ ] 监听器未清理（内存泄漏）
- [ ] 定时器未停（页面切换后仍在跑）
- [ ] WebSocket 未关闭

## 接口
- [ ] 无分页返回大数据
- [ ] N+1 查询
- [ ] 关键 SQL 缺索引
- [ ] 频繁全表 count(*)
- [ ] 缓存命中率低
- [ ] 同步调用应改异步
- [ ] 大事务长锁

## 数据库
- [ ] 慢查询无优化
- [ ] 索引过多影响写
- [ ] 分页 LIMIT 1000000, 20
- [ ] 死锁未处理

## 网络
- [ ] HTTP/1.1 串行加载
- [ ] CDN 未启用
- [ ] gzip / brotli 未启用
- [ ] 静态资源 cache-control 不合理
