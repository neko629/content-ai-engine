# 维度 12 · 兼容性测试

> 检查不同浏览器、设备、分辨率、操作系统环境下页面的显示与操作。

## Checklist

- 浏览器：Chrome / Edge / Safari / Firefox 主流版本 + 上 2 个版本
- 移动浏览器：iOS Safari / Android Chrome / 微信内置 / 企业微信内置
- 系统：Windows 10/11 / macOS / iOS 15+ / Android 8+
- 设备：手机 / 平板 / 桌面 / 大屏
- 分辨率：1920×1080 / 1440×900 / 1366×768 / 移动常见尺寸
- DPR：1x / 2x / 3x（图片清晰度）
- 网络：4G / 3G / Wi-Fi / 弱网
- 字体：未安装设计字体的降级
- 输入法：中文 / 日文 / 韩文 / 全角半角
- 触屏 vs 鼠标交互
- 横竖屏切换
- 系统暗色模式跟随
- 浏览器缩放（80% / 125% / 150%）
- 无障碍：屏幕阅读器、键盘导航、对比度

## 测试方法

1. Chrome DevTools 设备模拟器
2. `mcp__Claude_in_Chrome__resize_window` 切分辨率
3. BrowserStack / LambdaTest（如可用）
4. 真机测试（关键浏览器）

## 常见 Bug 模式

- Safari 不支持的新 API（如某些 :has() 用法）
- iOS 输入框聚焦时页面整体上推
- 微信内置浏览器自动给链接加颜色
- 企业微信内置浏览器无法触发原生分享
- DPR 2/3x 下图标模糊（用了位图未用 SVG）
- 横屏后布局错位
- 浏览器缩放下文字溢出
- 中文输入法未完成候选词时触发了 submit
- 键盘 Tab 失焦或循环失败

## 通过判定

- 覆盖目标浏览器/设备/分辨率矩阵
- 已知不兼容点有降级或明确"不支持"提示
- 输入法、横竖屏、缩放有验证
- 无障碍至少满足键盘可达 + 对比度 4.5:1
