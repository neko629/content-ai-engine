# 维度 13 · 性能与响应速度测试

> 检查页面加载、接口响应、列表加载、大数据量处理等是否存在明显卡顿或延迟。

## Checklist

### 前端
- 首屏渲染时间（FCP / LCP）
- 可交互时间（TTI）
- 累计布局偏移（CLS）
- 首次输入延迟（FID / INP）
- 包体大小：JS / CSS / 图片
- 资源懒加载：图片 / 路由分包 / 组件按需
- 长列表虚拟滚动
- 重复渲染（React DevTools Profiler）
- 字体加载策略（swap / optional）

### 接口
- P50 / P95 / P99 响应时间
- 大数据量分页
- N+1 查询
- 缓存命中率

### 综合
- 弱网下表现
- 大数据下表现（100 / 1000 / 10000 / 100000）
- 长时间停留（内存泄漏）
- 多 tab 共存

## 测试方法

1. Chrome Lighthouse 跑分
2. `mcp__Claude_in_Chrome__read_network_requests` 看资源/接口耗时
3. Performance 面板录制
4. `time curl` / `ab` 测接口
5. 准备大数据量测列表

## 常见 Bug 模式

- 首屏 LCP > 4s
- 包体未拆分，首屏加载所有路由代码
- 图片未压缩 / 未懒加载
- 接口未分页，一次返回 10w 数据
- N+1 查询（每条记录单独查关联）
- React 不必要的 re-render
- 内存泄漏（监听器未清、定时器未停）
- 长列表无虚拟滚动

## 通过判定

- LCP ≤ 2.5s / FID ≤ 100ms / CLS ≤ 0.1（Web Vitals）
- 关键接口 P95 ≤ 业务阈值
- 大数据量场景有分页或虚拟滚动
- 长时间停留无明显内存增长
