# 维度 02 · 页面 UI 布局测试

> 检查页面布局、颜色、字体、间距、图标、按钮、表格、弹窗等是否符合 UI 设计稿。

## Checklist（要看什么）

### 设计 Token 层
- 色值：背景 / 边框 / 文字 / 主题色 / 状态色（success/warning/error/info）
- 字号：H1–H6 / Body / Caption / Code
- 字重：Regular / Medium / Bold
- 行高：与字号配比是否一致
- 间距：4 / 8 / 12 / 16 / 24 / 32px 网格
- 圆角：4 / 8 / 12 / 16 / round
- 阴影：elevation 层级
- 图标尺寸：12 / 16 / 20 / 24 / 32

### 组件层
- 按钮：高度 / 宽度 / 内边距 / 图标位置 / Loading 态 / Disabled 态
- 输入框：高度 / 占位字色 / 聚焦边框 / 错误状态边框 / 后缀图标
- 表格：行高 / 表头样式 / 斑马纹 / hover 行 / 排序图标 / 固定列阴影
- 弹窗：宽度 / 圆角 / 阴影 / 遮罩透明度 / 关闭按钮位置
- 表单：标签对齐 / 标签宽度 / 必填星号位置 / 错误提示位置
- 标签 / Tag / Badge：颜色 / 圆角 / 内边距
- 头像：尺寸 / 圆形/方形 / 默认占位

### 状态层（每个组件 6 态齐备）
- 默认 / Hover / Active / Disabled / Error / Loading
- 列表的：空状态 / 加载态 / 错误态 / 部分加载 / 无更多

### 响应式层
- 断点：≤576 (xs) / ≤768 (sm) / ≤992 (md) / ≤1200 (lg) / ≤1600 (xl)
- 每个断点下的栅格、间距、字号是否符合稿
- 移动端：横竖屏切换、安全区、刘海屏

### 暗色模式（如适用）
- 所有色值是否有暗色 token
- 图片/图标是否做了暗色适配
- 切换瞬时是否有闪屏

## 测试方法

1. **Token 对比表**：
   ```
   | Token       | UI 稿值   | 实际 CSS 值 | 是否一致 |
   | primary     | #1677FF   | #1677FF     | ✓       |
   | spacing-md  | 16px      | 15px        | ✗ 偏差   |
   ```
2. **像素级对比**：用 `mcp__Claude_in_Chrome__get_screenshot` 与 UI 稿 `mcp__pencil__get_screenshot` 同尺寸截图对比
3. **组件状态矩阵**：每个组件按"6 状态"逐个截图
4. **断点遍历**：用 `mcp__Claude_in_Chrome__resize_window` 切换断点宽度，逐档截图
5. **DOM/CSS 检查**：Bash 用 grep 查 Tailwind class 或 CSS 变量
6. **暗色切换**：手动切换 `prefers-color-scheme` 或主题切换器

## 常见 Bug 模式

- 主题色偏差（#1677FF vs #1677ff vs #1976D2）
- 间距不符合 4/8px 网格（出现 7px / 13px / 19px 这种非常规值）
- 按钮高度非整数（实际渲染 31.5px）
- Loading 态缺失（按钮点完一直是默认态）
- 空状态缺失（列表无数据显示空白）
- 错误态缺失（接口失败页面崩溃）
- Hover/Focus 状态丢失（键盘 Tab 不可见）
- 移动端字号过小（< 12px）
- 移动端按钮过小（点击区域 < 44×44）
- 表格固定列阴影缺失，错位
- 弹窗在小屏被裁切
- 长文本不换行 / 不省略 / 溢出布局
- 头像加载失败无占位
- 暗色模式硬编码白色背景没切换
- 字体加载闪烁（FOIT/FOUT）

## 通过判定

- 设计 Token 表 100% 项一致（色值/字号/间距偏差 ≤ 1px 或同 HEX）
- 每个组件 6 状态齐备
- 主要断点（sm/md/lg）下截图与稿对照通过
- 长文本场景（标题、内容、表格单元）有省略或换行策略
- 暗色模式（如要求）整体可用，无白屏闪屏
- 移动端按钮/链接点击区域 ≥ 44×44px
