# 维度 06 · 异常场景与容错测试

> 检查接口失败、网络异常、数据为空、重复提交、页面刷新等异常情况下的容错处理。

## Checklist

- 接口失败（4xx/5xx）：错误提示 / 状态恢复 / 重试入口
- 网络断开：离线提示 / 重连机制 / 已输入数据是否保留
- 网络慢：loading 态 / 超时处理 / 用户可取消
- 数据为空：列表 / 详情 / 搜索结果 / 下拉选项
- 数据脏：null / undefined / 空字符串 / NaN / 嵌套缺失字段
- 重复提交：按钮点击多次、网络抖动重试
- 页面刷新：未保存数据丢失提示
- 浏览器后退：状态恢复
- 标签页切换：长任务的进度保持
- 异常退出：Token 过期、被强制下线、IP 异常
- 第三方依赖挂掉：地图、支付、登录、上传服务

## 测试方法

1. Chrome DevTools 限速 / 离线模式
2. 修改返回 mock 测异常路径
3. 关闭后端服务测 5xx
4. 关闭依赖第三方服务测降级
5. 手动 reload / back / 切 tab

## 常见 Bug 模式

- 接口失败页面崩白
- 重复点击产生重复订单
- 离线时仍显示 loading 永不结束
- 空数据展示 "undefined" / "[object Object]"
- 网络慢时已提交但按钮可再点
- 第三方挂掉无降级，整个页面不可用
- Token 过期未跳登录
- 强制下线无提示，操作后再 401
- Loading 后接口失败但 loading 状态未清除

## 通过判定

- 每个网络/数据失败路径都有兜底 UI
- 重要表单页面有"刷新/关闭"丢失数据提示
- 关键非幂等操作有防重复机制
- 第三方降级策略明确
