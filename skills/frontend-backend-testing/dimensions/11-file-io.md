# 维度 11 · 文件上传 / 下载 / 导入 / 导出测试

> 检查文件格式、大小限制、上传成功、下载完整、导入导出数据准确性等。

## Checklist

### 上传
- 允许的格式白名单 / 黑名单
- 大小上限（0B / 1B / 1MB / 100MB / 1GB / 超限）
- 文件名特殊字符 / 中文 / Emoji / 过长（255+）
- 同名文件覆盖策略
- 上传中断：网络断、关页面、取消按钮
- 进度展示
- 并发上传
- 病毒文件 / 假后缀（.exe 改 .jpg）

### 下载
- 大文件下载（流式 vs 一次性）
- 下载中断恢复
- 文件名中文乱码（Content-Disposition）
- 浏览器拦截策略
- 权限校验：登录态、所有权

### 导入
- 模板兼容（Excel / CSV）
- 列顺序变动是否报错
- 必填列缺失
- 数据格式错误的行级反馈
- 大文件导入（10w 行）
- 部分成功 vs 全部失败策略
- 重复数据冲突

### 导出
- 数据量大时分块（流式）
- 字段顺序与模板一致
- 中文不乱码（UTF-8 BOM）
- 公式注入安全（=cmd|... 防御）
- 含敏感字段是否按权限脱敏

## 测试方法

1. 准备各种边界文件（0B、1B、刚好限值、超限值、超长文件名）
2. 假文件（改后缀的 exe / 含宏的 xlsx）
3. Bash 用 dd 生成大文件测上传
4. 导入故意构造错误格式 / 多余列 / 缺列 / 重复行

## 常见 Bug 模式

- 只校验前端后缀，绕过可上传任意文件
- 大文件超限提示在上传完成后才报
- 上传中断没断点续传
- 下载中文文件名乱码
- 导入只返回"失败"不告知哪行错
- 导出按 limit 截断（只导 1000 条没提示）
- CSV 公式注入（用户名为 =cmd|'/c calc'!A0）
- 文件存储路径可猜测（/uploads/123.jpg）能被遍历

## 通过判定

- 文件格式/大小双层校验（前端 + 接口）
- 文件名编码安全
- 上传/下载边界齐备
- 导入有行级反馈，导出无截断
- 安全防御（病毒扫描、CSV 注入、路径遍历）已考虑
