# 测试用例表模板

## 字段定义

| 字段 | 说明 | 是否必填 |
|---|---|---|
| 编号 | TC001 格式 | 必填 |
| 模块 | 所属模块 | 必填 |
| 维度 | 21 个维度之一 | 必填 |
| 测试场景 | 一句话描述 | 必填 |
| 优先级 | P0/P1/P2 | 必填 |
| 测试方法 | 等价类/边界值/判定表/状态迁移/正交/场景/错误推测 | 必填 |
| 前置条件 | 测试需要的状态 | 必填 |
| 数据准备 | 需要的测试数据 | 选填 |
| 操作步骤 | 编号化、可执行 | 必填 |
| 预期结果 | 客观可判定 | 必填 |
| 实际结果 | 含"未实测"标注 | 必填 |
| 是否通过 | PASS/FAIL/未测 | 必填 |
| 关联接口 | URL + 方法 | 选填 |
| 自动化 | 是/否/已实现 | 选填 |
| 备注 | | 选填 |

## 示例

| 编号 | 模块 | 维度 | 场景 | P | 方法 | 前置 | 步骤 | 预期 | 实际 | 通过 |
|---|---|---|---|---|---|---|---|---|---|---|
| TC001 | 登录 | 01 | 正常登录 | P0 | 场景 | 未登录 | 1.输入正确账号；2.输入正确密码；3.点登录 | 跳转 /home，header 显示用户名 | 已实测 PASS | ✓ |
| TC002 | 登录 | 05 | 密码长度边界 min-1 | P0 | 边界值 | 账号已填 | 1.密码输入 5 字符；2.点登录 | 提示"密码至少 6 位"，停留登录页 | 未实测，待验证 | - |
| TC003 | 登录 | 14 | XSS payload 防御 | P0 | 错误推测 | 未登录 | 1.账号输入 `<script>alert(1)</script>`；2.点登录 | 不弹窗，账号原样发送或转义 | 已实测 PASS | ✓ |
| TC004 | 登录 | 08 | Token 过期跳转 | P1 | 场景 | 已登录，Token 已改为过期 | 1.点击任意需鉴权链接 | 跳 /login，带 redirect 参数 | 未实测 | - |

## 编写要求

- 每个场景至少 1 个正向 + 1 个反向用例
- 步骤具体到"点哪个按钮、填什么内容"
- 预期可被客观判定（不写"显示正常"）
- 涉及接口的，关联接口栏填路径
- 未实测的用例"实际结果"显式标注"未实测，待验证"
