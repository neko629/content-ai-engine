# 测试计划模板（用于"测试编排"模式）

```
# [项目] 测试计划

## 1. 测试目标
[一句话]

## 2. 测试范围
- 包含：[模块/页面/接口列表]
- 排除：[显式排除]

## 3. 维度优先级
| 维度 | 优先级 | 理由 |
| 02 UI 布局 | P0 | 客户最关注 |
| 03 接口联调 | P0 | 上线核心 |
| 18 静态分析 | P1 | 代码质量 |
| …… |

## 4. 测试批次
| 批次 | 内容 | 维度 | 入参 | 产出 | 预估时长 |
| 第 1 批 | 主流程冒烟 | 01/02/03 | 原型 + 接口文档 | 冒烟报告 | 1 天 |
| 第 2 批 | UI 深测 | 02 | UI 稿 + 运行环境 | UI 测试报告 | 2 天 |
| 第 3 批 | 接口深测 | 03/04/14 | 接口文档 + 后端代码 | 接口报告 | 2 天 |
| …… |

## 5. 风险评估
- 高风险点：……
- 资源缺口：……

## 6. 退出条件
- P0 用例 100% PASS
- 严重 Bug 全部修复
- ……

## 7. 责任分工
- Claude：执行测试、生成报告、汇总 Bug
- 用户：提供材料、审阅计划、确认 Bug、提供运行环境
```
