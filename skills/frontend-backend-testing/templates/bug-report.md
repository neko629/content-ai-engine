# Bug 报告模板

## 字段定义

| 字段 | 内容 |
|---|---|
| Bug ID | BUG-001 |
| 标题 | [模块] 一句话描述 |
| 所属模块 | |
| 关联维度 | 21 个维度之一 |
| 严重程度 | 严重 / 一般 / 轻微 |
| 优先级 | P0 / P1 / P2 |
| 复现率 | 必现 / 偶现 / 待复现 |
| 环境 | URL / 浏览器 / 版本 / 账号 |
| 前置条件 | |
| 复现步骤 | 1. …… 2. …… 3. …… |
| 预期结果 | |
| 实际结果 | |
| 截图 / 录屏 | 路径 |
| 接口信息 | 路径、入参、响应 |
| 控制台报错 | |
| 修改建议 | |
| 影响范围 | |
| 关联用例 | TC001 等 |
| 状态 | 新建 / 已确认 / 修复中 / 待验证 / 已验证 / 关闭 / 重开 |

## 严重程度判定

- **严重**：阻塞主流程 / 数据错误丢失 / 权限失控 / 登录无法完成 / 支付订单异常 / 安全漏洞
- **一般**：功能可用但不符合预期，影响部分用户操作或体验，但存在变通
- **轻微**：样式偏差、文案错误、提示不够友好等不影响功能

## 示例

```
[BUG-007]
标题：[登录] XSS payload 在错误提示中未转义，可触发 alert
所属模块：登录
维度：14 安全性
严重程度：严重
优先级：P0
复现率：必现
环境：https://staging.example.com/login，Chrome 121，账号 test@example.com

前置条件：未登录

复现步骤：
1. 打开 /login
2. 账号输入：<script>alert(1)</script>@a.com
3. 密码输入：任意
4. 点击"登录"按钮
5. 接口返回 401，前端展示错误提示

预期结果：错误提示内容被转义，不执行任意脚本

实际结果：弹出 alert(1)，证明存储/反射型 XSS 存在

截图：/uploads/bug-007.png
接口：POST /api/v1/auth/login，body 含原始 payload，响应 401 含原始 payload

修改建议：
1. 前端展示错误提示时统一用 textContent 而非 innerHTML
2. 后端 error message 也应过滤
3. 全站引入 CSP 头

影响范围：所有展示用户输入的错误/提示位置可能都有
关联用例：TC003
状态：新建
```
