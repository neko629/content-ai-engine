# 测试矩阵模板

## 用法

复杂场景（多变量组合）用矩阵展开，避免线性用例表漏测。

## 模板结构

```
变量定义：
- 变量 A：值1 / 值2 / 值3
- 变量 B：值1 / 值2
- 变量 C：值1 / 值2 / 值3

矩阵：
| #  | A   | B   | C   | 预期 | 实际 | PASS |
| 1  | 值1 | 值1 | 值1 | …   | …   | …    |
| 2  | 值1 | 值1 | 值2 | …   | …   | …    |
| …  |
```

## 典型场景模板

### 角色 × 资源 × 操作（权限矩阵）

| 角色\操作 | 查看 | 新增 | 编辑 | 删除 | 导出 |
|---|---|---|---|---|---|
| 超管 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 管理员 | ✓ | ✓ | ✓ | ✗ | ✓ |
| 普通员工 | ✓（本部门）| ✗ | ✗ | ✗ | ✗ |
| 访客 | ✗ | ✗ | ✗ | ✗ | ✗ |

每格 = 1 个用例（UI + 接口双层）。

### 端 × 浏览器 × 网络

见 `methods/orthogonal-array.md`。

### 状态 × 操作（状态机操作矩阵）

| 状态\操作 | 编辑 | 提交 | 撤回 | 删除 |
|---|---|---|---|---|
| 草稿 | ✓ | ✓ | ✗ | ✓ |
| 已提交 | ✗ | ✗ | ✓ | ✗ |
| 已通过 | ✗ | ✗ | ✗ | ✗ |
| 已拒绝 | ✓ | ✓ | ✗ | ✓ |

每个 ✗ 对应一个"非法操作被拒绝"用例。
