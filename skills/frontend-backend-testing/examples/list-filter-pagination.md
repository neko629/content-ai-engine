## 工具实测

```bash
# 接口层测分页边界
curl 'https://api.example.com/v1/orders?page=0&size=20'
curl 'https://api.example.com/v1/orders?page=-1&size=20'
curl 'https://api.example.com/v1/orders?page=1&size=999999'
curl 'https://api.example.com/v1/orders?sort=invalid_field'

# 性能：大数据
curl 'https://api.example.com/v1/orders?page=10000&size=20' -w '%{time_total}\n' -o /dev/null
```

## 常见 Bug
- 切筛选未重置页码（搜出来在第 5 页但只有 2 页）
- 分页参数不在 URL
- 排序后分页错位（接口未带稳定排序）
- 多筛选用 OR 不是 AND
- 翻页快切导致旧请求覆盖新请求

## 通过判定
- 数据量 0/1/整页/非整页/超大 五档已测
- 搜索 × 筛选 × 排序 × 分页 四要素组合已覆盖
- URL 参数化
- 删除/筛选切换的边界处理正确
