# 示例 · 表单 + 校验（重点：维度 05 输入校验）

## 用户输入
> "这是注册页表单，帮我测一下所有字段的校验。"

## 字段清单
- 用户名：4–20 字符，字母数字下划线
- 邮箱：标准邮箱格式
- 手机号：中国大陆 11 位
- 密码：8–32 字符，需包含大小写 + 数字
- 确认密码：与密码一致
- 验证码：6 位数字
- 同意协议：必勾

## 测试设计

每字段按"等价类 + 边界值"展开，使用 `methods/equivalence-partitioning.md` + `methods/boundary-value.md`。

### 用户名

| 用例 | 输入 | 预期 |
|---|---|---|
| 空 | `""` | 提示必填 |
| 纯空格 | `"   "` | 提示必填（trim 后空）|
| 长度 3 | `"abc"` | 至少 4 字符 |
| 长度 4 | `"abcd"` | PASS |
| 长度 20 | 20 字符 | PASS |
| 长度 21 | 21 字符 | 最多 20 字符 |
| 含中文 | `"用户1"` | 仅支持英文数字下划线 |
| 含 Emoji | `"abc😀"` | 同上 |
| 含特殊字符 | `"abc!@#"` | 同上 |
| 首尾空格 | `" abc "` | trim 后 PASS（或提示） |
| 已注册 | `"existing"` | 接口提示用户名已被使用 |

### 邮箱

| 用例 | 输入 | 预期 |
|---|---|---|
| 标准 | `a@b.com` | PASS |
| 带 + | `a+tag@b.com` | PASS |
| 带 . | `a.b@c.com` | PASS |
| 无 @ | `abcd` | 格式错误 |
| 无后缀 | `a@b` | 格式错误 |
| 中文域名 | `a@中国.cn` | 业务约定 |
| 超长 | 256 字符 | 长度超限 |

### 手机号

| 用例 | 输入 | 预期 |
|---|---|---|
| 标准 | `13800138000` | PASS |
| 10 位 | `1380013800` | 长度错 |
| 12 位 | `138001380000` | 长度错 |
| 含字母 | `13800138a00` | 格式错 |
| 非 1 开头 | `23800138000` | 格式错 |
| 含空格 | `138 0013 8000` | 业务定（一般 trim 后 PASS）|
| 港澳台号码 | `+852-xxxx` | 业务定 |

### 密码（强度规则）

| 用例 | 输入 | 预期 |
|---|---|---|
| 全字母 | `abcdefgh` | 需含数字 |
| 全数字 | `12345678` | 需含字母 |
| 无大写 | `abcd1234` | 需含大写 |
| 无小写 | `ABCD1234` | 需含小写 |
| 长度 7 | `Aa12345` | 至少 8 |
| 长度 8 | `Aa123456` | PASS |
| 长度 33 | 33 字符 | 最多 32 |
| 与用户名相同 | `abcd1234` 用户名也是这个 | 不能与用户名相同 |
| 含空格 | `Aa12 3456` | 业务定 |

### 确认密码

| 用例 | 预期 |
|---|---|
| 与密码一致 | PASS |
| 与密码不一致 | 提示不一致 |
| 密码改了确认密码未改 | 实时校验提示 |

### 跨字段联动
- 改用户名后，"用户名已被使用"提示应实时消除
- 改密码后，确认密码状态应重新校验
- 验证码错误后，应允许重新获取

### 提交时
- 全部合法 → 提交成功
- 任意一项不合法 → 阻止提交，聚焦第一个错误字段
- 提交中按钮 loading + 不可再点
- 服务端错误（账号已存在）→ 字段级错误提示

## 工具实测

```bash
# 直接打接口绕过前端校验
curl -X POST https://api.example.com/v1/register \
  -H 'Content-Type: application/json' \
  -d '{"username":"","email":"x","mobile":"123","password":"abc"}'
```

预期：接口返 400 含字段级错误数组。

## 常见 Bug
- 前端校验通过但接口未校验（绕过前端可注册脏数据）
- 必填校验放过纯空格
- 长度按字符算但 DB 按字节算
- 校验错误提示用代码不是人话

## 通过判定
- 每字段边界值用例齐备
- 前后端双校验
- 跨字段联动正确
- 提交成功 + 失败两路径均有测试
