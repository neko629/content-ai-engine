## 2. 结构化清单字段建议

- 功能点 F-xx：名称 / 所属模块 / 验收要点
- 业务规则 R-xx：触发条件 / 处理逻辑 / 边界与异常
- 页面交互 P-xx：组件 / 状态(正常·空·加载·错误·禁用) / 跳转 / 交互节点
- 架构约束：分层 / 目录 / 技术栈 / 命名 / 接口契约(路径·方法·入参·返回·错误码)
- 字段表：名称 / 类型 / 必填 / 约束 / 来源
