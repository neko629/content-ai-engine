## 素材 1：截图文字描述（模拟视觉素材）

```
顶部：
- 状态栏（系统）
- 导航栏 56px：左侧返回箭头、中间标题"夏季新品"、右侧购物车图标（带红点角标 "3"）
- 搜索框 36px：占据宽度 90%，居中，灰色背景 #F5F5F5，圆角 18px，
  左侧 🔍 图标，placeholder "搜索商品 / 品牌"

筛选栏 44px（吸顶）：
- 横向滚动 chip：综合 / 销量 / 新品 / 价格升序 / 价格降序 / 筛选⛂
- 当前激活：综合（粉色下划线 4px 高）

商品列表（2 列瀑布流）：
- 卡片背景 #FFF，圆角 8px，间距 8px，左右边距 12px
- 卡片结构：
  - 商品图 1:1，圆角 8px（顶部），右下角商品视频标记（如有）
  - 内容区 padding 8px：
    - 第一行：商品标题 14px / 加粗 / 最多 2 行 / 超出省略
    - 第二行：销量标签 #FFE5E5 背景 + "已售 1.2k"
    - 第三行：价格 ￥328 红色 + 划线原价 ￥499 灰色 + 加车按钮 ⊕（右对齐）

底部：
- TabBar 60px：首页 / 分类 / 购物车（红点 "3"）/ 我的
- iOS 安全区域 34px
```

## 素材 2：PRD 节选

```
产品名称：XX 电商小程序
页面名称：商品列表页（分类入口）
业务定位：电商核心导购页，承接 banner / 类目 / 推荐位流量

核心功能：
1. 展示符合分类条件的商品列表
2. 支持 5 种排序：综合 / 销量 / 新品 / 价格升序降序
3. 支持高级筛选（价格区间 / 品牌 / 折扣 / 是否包邮）
4. 商品卡片支持快速加车（不进详情）
5. 已加车商品在角标 +1

边界：
- 列表无数据时显示空插画 + "试试调整筛选条件"
- 加载失败显示重试
- 未登录点击"加车"跳登录
- 库存为 0 时按钮置灰 + "已售罄"

性能要求：
- 首屏 1s 内出第一屏
- 滚动 60fps
- 图片懒加载
```
