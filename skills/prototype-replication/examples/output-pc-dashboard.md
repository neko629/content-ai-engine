⚠️ 资料完整度：**完整**（PRD + 截图描述 + 已上线参考）

## 1. 页面概述

- **页面名称**：数据总览 Dashboard
- **页面目标**：B 端用户每日打开的第一页，承担"看清问题 → 选择下钻路径"
- **核心功能**：4 核心指标 + 趋势图 + Top5 排行 + 明细表 + 全局时间 + 数据导出 + 多角色权限
- **目标用户**：B 端运营 / 客户成功 / 销售；高频使用 ≥3 次/天；多浏览器 + 多分辨率
- **业务定位**：SaaS 运营后台核心入口（PRD §1）

---

## 2. 布局说明

- **整体宽度**：min 1280px，max 1920px，超大屏内容居中 1920px 上限
- **整体结构**：TopBar(56px) + LeftNav(200px 可折叠 64px) + MainContent
- **MainContent**：padding 24px；自上而下 4 行（时间筛选 / 指标卡 / 趋势图+排行 / 明细表）
- **栅格系统**：12 列，col-gap 16px
- **响应式断点**：
  - <1280px：左导航强制折叠为图标态；指标卡 2×2
  - 1280-1600px：指标卡 4 列；趋势图 8 col / 排行 4 col
  - >1600px：内容区不再变宽，左右留白
- **暗色模式**：支持（PRD §6 可选）

## 4. 交互说明

> 默认 B 编号清单型，按 ①-⑨ 九维度展开

### [✓ 可见] 4.1 切换时间筛选器（chip）

① **触发条件**：PC 单击 chip / Enter / Space / 方向键
② **即时反馈**：chip 按下态 opacity 0.85（80ms）+ 焦点环 2px outline
③ **处理表现**：全页 4 模块进入骨架屏；时间 chip 显示 spinner；指标卡 / 图表 / 排行 / 表格并发 fetch
④ **成功状态**：所有数据更新；chip 切换为选中蓝色
⑤ **失败异常**：
   - 网络断 → toast "网络异常" + chip 回滚；保留旧数据
   - 接口超时（5s）→ toast "请求超时，点击重试" + 重试按钮
   - 部分接口失败 → 其它模块正常显示，失败模块显示错误态
   - 鉴权过期 → 全局跳登录页 + 登录后续接
   - 短时间反复切换 → 防抖 300ms + 取消旧请求
⑥ **边界处理**：自定义时间不可选未来；最大跨度 365 天；跨时区显示本地+服务器时区
⑦ **动效参数**：
   - 按下态：80ms · ease-out
   - chip 切换：200ms · ease-in-out
   - 骨架闪烁：2000ms · ease-in-out · 循环
⑧ **无障碍**：每个 chip aria-pressed；键盘方向键切换；焦点环可见；屏幕阅读器播报"已切换至 X"
⑨ **性能预算**：防抖 300ms；并发请求合并；后端缓存 5min；首次切换 <800ms

---

### [✓ 可见] 4.2 指标卡 hover 详情 tooltip

① **触发条件**：鼠标悬停 ⓘ 图标
② **即时反馈**：图标 #3B82F6 高亮
③ **处理表现**：悬停 200ms 后弹 tooltip（避免误触）
④ **成功状态**：tooltip 显示指标定义 / 计算口径 / 数据源
⑤ **失败异常**：
   - 触屏设备无 hover → tap ⓘ 触发同样 tooltip
   - 多个 tooltip 同时悬停 → 仅显示最后一个
   - tooltip 超出视口 → 自动翻转方向
⑥ **边界处理**：tooltip 最大宽 320px，超出换行；含 link 时阻止鼠标移开消失
⑦ **动效参数**：
   - 出现：150ms · ease-out · 200ms delay
   - 消失：100ms · ease-in · 0ms delay
⑧ **无障碍**：aria-describedby；键盘 focus 时也显示；Esc 关闭
⑨ **性能预算**：tooltip 内容延迟渲染（首次 hover 后才挂载 DOM）

---

### [✓ 可见] 4.3 趋势图 tab 与粒度切换

① **触发条件**：单击 tab 或粒度 chip / 键盘 Tab+Enter
② **即时反馈**：选中 tab 蓝色高亮，下方 2px 蓝条
③ **处理表现**：图表 fade-out 200ms → 骨架屏 → fetch → fade-in 300ms 绘制
④ **成功状态**：图表更新；保留 hover/zoom 状态
⑤ **失败异常**：
   - 网络/超时 → 图表区域错误态 + 重试按钮
   - 切换粒度后数据点过多（>1000）→ 后端聚合
   - 切换 tab 时旧请求未完成 → 取消旧请求
   - 该指标无权限 → 显示 🔒 + "无权访问"
⑥ **边界处理**：小时粒度仅最近 7 天；月粒度最大 24 月；空数据显示"暂无数据"
⑦ **动效参数**：
   - 淡入淡出：200/300ms · ease-out
   - 柱状图 stagger：每条 +30ms 入场
⑧ **无障碍**：tab role="tab" + aria-selected；键盘左右切换；图表可导出 CSV 替代视觉
⑨ **性能预算**：图表渲染 60fps；数据点 >500 时降采样；canvas 绘制硬件加速

---

### [✓ 可见] 4.4 数据导出（同步 vs 异步）

① **触发条件**：单击"导出"下拉 → 选 CSV / Excel；权限够时显示"包含敏感字段"开关
② **即时反馈**：按钮 loading 200ms
③ **处理表现**：
   - 数据量 <1w 行：同步导出，浏览器下载弹窗
   - 数据量 >1w 行：异步导出，toast "导出任务已创建，完成后通知"
④ **成功状态**：
   - 同步：浏览器自动下载
   - 异步：消息中心新通知 + 红点；点击下载链接
⑤ **失败异常**：
   - 同步超时 → 自动降级为异步
   - 异步任务失败 → 消息中心通知 + 重试链接
   - 无权限字段 → 提示"以下字段无权导出：xxx"
   - 重复点击 → 防抖 2s（导出操作较重）
   - 浏览器拦截下载 → toast 提示放行
⑥ **边界处理**：单次最大 100w 行；超出建议分批；敏感字段开关需二次确认
⑦ **动效参数**：
   - 下拉弹出：200ms · ease-out
   - toast：200ms 出 + 250ms 消 · 2000ms 停留
⑧ **无障碍**：按钮 aria-label="导出数据"；下拉 role="menu"；快捷键 Cmd+Shift+E
⑨ **性能预算**：导出任务不阻塞主线程；前端不在内存中生成大文件

### [✓ 可见] 4.5 明细表行 hover + 右键

① **触发条件**：鼠标悬停行 / 右键
② **即时反馈**：行背景 #EFF6FF；操作列按钮显现
③ **处理表现**：右键弹自定义菜单（查看/复制/导出该行）
④ **成功状态**：操作列点击执行对应动作
⑤ **失败异常**：

⑦ **动效参数**：

⑧ **无障碍**：行 role="row"，单元格 role="cell"；键盘方向键导航单元格；Enter 触发操作
⑨ **性能预算**：表格虚拟滚动（>200 行）；hover 节流 16ms

## 5. 状态说明

### 5.1 加载态
- 触发：首次进入 / 切换时间 / 切换 tab / 刷新
- 展示：分模块骨架屏（指标卡 / 图表 / 表格各自独立骨架）+ 顶部全页 loading 进度条（2s 内不显示）

### 5.2 空数据态
- 触发：筛选无结果 / 该指标无数据
- 展示：模块内 280×200 空插画 + 文案 + CTA "调整筛选条件"

### 5.3 错误态
- 触发：接口 5xx / 接口超时（>5s）/ 网络断
- 展示：错误图标 + "加载失败，点击重试" + 重试按钮（在出错模块内，不影响其它）
- 重试策略：手动；连续 3 次失败提示"请联系管理员"

### 5.4 权限态
- 触发：用户无权访问字段 / 模块
- 展示：字段 *** 🔒；整模块时显示"无访问权限" + "申请权限"按钮

### 5.5 数据计算中
- 触发：凌晨 0-2 点访问昨日 T+1 数据
- 展示：黄色提示条 "数据计算中，请稍后刷新" + 当前已可见的隔日数据

### 5.6 鉴权过期
- 触发：session 过期（默认 8h）
- 展示：modal "登录已过期" + "重新登录" CTA；登录后续接

### 切换逻辑
```
进入页面 → 鉴权
  ├─ 通过 → 加载态 → 正常态 / 错误态 / 空数据态 / 数据计算中
  └─ 未通过 → 鉴权过期 → 登录后回到正常态

正常态 ↔ 切换筛选 ↔ 加载态 → 正常态 / 错误态
正常态 → 导出 → 同步成功 / 异步任务创建
错误态 → 重试 → 加载态
权限态 → 申请权限 → 工单提交（不在本页处理）
```

## 6. 复刻建议

> 以下为建议，由用户决定是否采纳。

### 6.1 还原度评估（三维）

- **结构还原度**：95% — 全 7 个 P0 模块对应截图与 PRD
- **交互还原度**：90% — 4.6 全局快捷键为推定；4.7 拖拽布局不确定
- **状态还原度**：95% — 6 种状态全覆盖；缺"导出失败重试 UX"细节

### 6.2 优化建议

- **[建议] 全局刷新快捷键**：建议改为 Cmd+Shift+R（避免与浏览器 Cmd+R 冲突重载）；原因 → 体验一致；预期 → 误触率下降
- **[建议] 指标卡 hover 时显示迷你趋势线**：sparkline 64×24，原因 → 在不下钻情况下直接感知趋势；预期 → 提升信息密度
- **[建议] 时间筛选器添加"自动刷新"开关**：每 N 分钟自动 refetch，原因 → 运营场景需要近实时；预期 → 减少手动刷新
- **[建议] 明细表列设置持久化到 localStorage**：原因 → 用户期望保留；预期 → 提升回访体验
- **[建议] 暗色模式适配检查**：所有阴影 / 边框需重新设计，原因 → 暗色下浅阴影看不见；预期 → 视觉一致性

### 6.3 技术注意事项

- 数据接口必须支持并发（指标卡 4 / 图表 1 / 排行 1 / 表格 1 共 7 个）
- 趋势图使用 echarts，按需引入避免打包过大
