## 素材 1：完整 PRD

```
产品名称：XX SaaS 运营后台
页面名称：数据总览 Dashboard
业务定位：B 端运营 / 客户成功 / 销售人员每日打开的第一页，承担"看清问题 → 选择下钻路径"

核心功能：
1. 顶部 4 个核心指标卡片（GMV / 订单数 / DAU / 转化率），含同环比
2. 中部时间趋势图（折线 + 柱状混合），可切换粒度（小时/天/周/月）
3. 中部右侧 Top 5 商品排行（销量 / GMV / 退款率 三 tab）
4. 底部分模块明细表（订单 / 用户 / 售后）+ 翻页 + 列设置
5. 全局时间筛选器（今日 / 昨日 / 本周 / 本月 / 自定义）
6. 数据导出（CSV / Excel）
7. 多角色权限（运营见全部 / 客户成功只见自己负责的客户）

目标用户：
- B 端运营、客户成功、销售人员
- 高频使用（每日 ≥3 次）
- 多浏览器（Chrome 90%+ / Safari / Edge）
- 屏幕 13-27 寸都要适配

边界 / 异常：
- 数据准时性 T+1，凌晨 0-2 点显示"昨日数据计算中"
- 大数据量（>10w 行）需要异步导出 + 完成后通知
- 接口超时（5s）→ 重试按钮 + 上报埋点
- 跨时区用户 → 显示本地时区 + 服务器时区标注

性能：
- 首屏 <2s
- 切换时间筛选器 <800ms
- 表格分页 <500ms
- 图表渲染 60fps（鼠标悬停 tooltip 流畅）

权限：
- 超级管理员：全部
- 运营：全部 + 不可导出敏感字段
- 客户成功：仅自己负责客户
- 销售：仅自己业绩范围
- 未授权字段显示 "***" 并标 🔒
```

## 素材 2：截图描述

```
顶栏（高 56px，吸顶）：
- 左：产品 logo + 切换租户下拉
- 中：搜索框（全局，支持订单号/用户ID/商品ID）
- 右：消息中心铃铛（红点）/ 帮助 / 用户头像下拉

左侧导航（宽 200px，可折叠为 64px 图标态）：
- 总览（当前）/ 订单 / 商品 / 用户 / 营销 / 财务 / 设置

主内容区（顶栏下方 + 左导航右侧，padding 24px）：

第一行：时间筛选器
- 高 36px，水平排列：今日 / 昨日 / 本周 / 本月 / 自定义
- 自定义打开日期范围 picker
- 右侧：刷新按钮 / 导出按钮（含下拉选 CSV/Excel）

第二行：4 张指标卡片，4 列等宽，间距 16px
- 卡片高 120px，圆角 8px，白底，阴影
- 卡片结构：
  - 第一行：指标名（13px 灰）+ 信息 ⓘ icon
  - 第二行：核心数字 28px 加粗
  - 第三行：同比 ↑5.3% 绿 / 环比 ↓2.1% 红

第三行：左右两块
- 左：趋势图卡片（占 66%，高 380px）
  - 顶部 tab：GMV / 订单数 / DAU / 转化率
  - 顶部右侧：粒度切换：小时 / 天 / 周 / 月
  - 图表：折线 + 柱状混合
  - 鼠标悬停：tooltip 显示完整数据
- 右：Top 5 排行（占 33%，高 380px）
  - 顶部 3 tab：销量榜 / GMV 榜 / 退款率榜
  - 列表 5 项：商品图 48×48 + 商品名 + 数据 + 排名徽章

第四行：明细表（全宽，高度自适应）
- 顶部 3 tab：订单 / 用户 / 售后
- 表格头：可拖拽排序、可隐藏列、固定首列
- 行：默认 56px，hover 浅蓝
- 操作列：查看 / 处理 / 备注
- 分页器：底部，每页 10/20/50/100
```
