# 商品列表页 原型说明文档

⚠️ 资料完整度：**中等**（截图描述 + PRD 节选，无线上链接 / 实测数据）
⚠️ 还原度评估：结构 90% · 交互 75% · 状态 85%

---

## 1. 页面概述

- **页面名称**：商品列表页（分类入口）
- **页面目标**：承接 banner / 类目 / 推荐位流量，让用户高效浏览、筛选、加车
- **核心功能**：分类商品展示、5 维排序、高级筛选、卡片快速加车
- **目标用户**：移动端 C 端消费者（已登录或游客）
- **业务定位**：电商核心导购页（PRD §1）

---

## 2. 布局说明

- **整体宽度**：375px 基准（iPhone 14），左右边距 12px
- **整体结构**：StatusBar + Header(56px) + SearchBar(36px+12px 间距) + FilterBar(44px 吸顶) + ProductGrid + TabBar(60px) + SafeArea(34px)
- **栅格系统**：2 列瀑布流，间距 8px，卡片宽度 (375-12*2-8)/2 ≈ 171px
- **响应式断点**：320 / 375 / 414 三档；横屏时切换为 3 列

## 4. 交互说明

> 默认 B 编号清单型，按 ①-⑨ 九维度展开

### [✓ 可见] 4.1 排序 chip 切换

① **触发条件**：tap 任意 chip（移动端单击）
② **即时反馈**：chip 按下态背景透明度 60%（80ms）+ haptic light
③ **处理表现**：列表淡出 200ms → 显示骨架屏 → fetch → 淡入新数据 200ms
④ **成功状态**：选中 chip 出现粉色下划线 4px；列表更新；滚动位置 reset 到顶
⑤ **失败异常**：
   - 网络断 → toast "网络异常，请重试" + 保留旧数据 + chip 回滚
   - 接口 5xx → toast "服务繁忙，请稍后重试"
   - 接口超时（>8s）→ toast "请求超时" + 重试按钮
   - 已选 chip 再点 → 无反应（节流）
   - 短时间内反复切换 → 防抖 300ms，仅响应最后一次
⑥ **边界处理**：滚动加载中切换 chip → 取消旧请求；旧数据立即清空
⑦ **动效参数**：
   - 按下态：80ms · ease-out · 0
   - 下划线滑动：200ms · ease-in-out · 0
   - 列表淡入淡出：200ms · ease-out · 0
⑧ **无障碍**：每个 chip aria-label="排序方式：xxx"；触摸目标 ≥44×44；键盘可达
⑨ **性能预算**：切换 chip 防抖 300ms；fetch 取消旧请求；骨架屏避免空白闪烁

---

### [✓ 可见] 4.2 商品卡片点击进详情

① **触发条件**：tap 卡片非加车按钮区域
② **即时反馈**：卡片 scale(0.98) 100ms + opacity 0.95
③ **处理表现**：路由切换前显示半透明 loading 遮罩（200ms 内立即跳转，超过则升级 loading）
④ **成功状态**：右滑过渡动画跳至 /product/{id}，保留滚动位置以便返回
⑤ **失败异常**：
   - 商品已下架（404）→ toast "商品已下架" + 不跳转
   - 鉴权过期 → 跳登录页 + 登录后续接
   - 网络断 → toast "网络异常"
   - 重复点击 → 防抖 300ms 内忽略
   - 商品 ID 无效 → 不跳转 + 上报埋点
⑥ **边界处理**：卡片在加车 loading 中也可点击进详情；详情页返回时列表保持原滚动位置和筛选状态
⑦ **动效参数**：
   - 按下态：100ms · ease-out
   - 页面切换：300ms · ease-in-out · 0
⑧ **无障碍**：整个卡片 role="link" + aria-label="{商品名}, {价格}"；触摸目标 ≥48×48
⑨ **性能预算**：路由预取（hover/即将到达视口时预加载详情）；详情页骨架屏 <500ms 出现

---

### [✓ 可见] 4.3 加车按钮（卡片内）

> 详细示例已在 SKILL.md §4.9 给出，此处仅列要点。

① **触发条件**：tap 卡片右下角 ⊕ 图标，**阻止冒泡**（不进详情）
② **即时反馈**：按钮 scale(0.94) 120ms + haptic medium
③ **处理表现**：图标 → 旋转 loading；<2s 内响应
④ **成功状态**：toast "已加入购物车" 2s + 顶部 / 底部购物车角标 +1 spring + 撤销 5s
⑤ **失败异常**：网络断 / 超时 / 鉴权过期 / 库存不足 / 重复点击 5 路（参见 SKILL.md §4.9）
⑥ **边界处理**：售罄置灰；连续 3 次失败禁用 10s
⑦ **动效参数**：120ms · ease-out · 0；角标 spring stiffness 400 damping 25
⑧ **无障碍**：aria-label="加入购物车"；触摸目标 ≥48×48；键盘 Enter 触发
⑨ **性能预算**：防抖 300ms；乐观更新角标；prefers-reduced-motion 时关 spring

### [? 推定] 4.4 下拉刷新（按通用 H5 列表模式推定）

① **触发条件**：列表顶部下拉 ≥80px 释放
② **即时反馈**：下拉时 logo 跟随 + 旋转角度随下拉距离

⑧ **无障碍**：屏幕阅读器可触发刷新（"双指上滑"或 toolbar 按钮）

## 5. 状态说明

### 5.1 加载态
- 触发：进入页面 / 切换排序 / 切换筛选 / 加载下一页
- 展示：骨架屏（卡片 placeholder，opacity 闪烁 1500ms 循环）+ 顶部 loading 进度条
- 时长：通常 <1s（PRD 性能要求）

### 5.2 空数据态
- 触发：筛选后无结果
- 展示：280×280 空插画 + "没有符合条件的商品" + "试试调整筛选条件吧" + CTA "清空筛选"
- CTA 行为：重置筛选条件并重新加载

### 5.3 错误态
- 触发：网络失败 / 接口 5xx / 接口超时（>8s）
- 展示：错误图标 + "网络异常，点击重试" + 重试按钮
- 重试策略：手动重试；连续失败 3 次后提示"请检查网络后重试"

### 5.4 权限态（未登录）
- 触发：未登录用户点击"加车"
- 展示：底部弹 sheet "登录后即可加车" + "立即登录"主按钮 + "稍后"次按钮
- 登录成功后：自动执行加车 + 弹成功 toast

### 切换逻辑
```
进入页面 → 加载态 → 正常态 / 错误态 / 空数据态
切换排序/筛选 → 加载态 → 正常态 / 空数据态
加车 → 校验登录 → 已登录加车 / 未登录权限态
加载下一页 → 局部加载态 → 追加成功 / 失败重试
```

## 6. 复刻建议

> 以下为建议，由用户决定是否采纳。

### 6.1 还原度评估（三维）

- **结构还原度**：90% — 所有 P0/P1 模块已在截图描述中覆盖
- **交互还原度**：75% — 4.4 下拉刷新为推定；4.5 长按多选不确定
- **状态还原度**：85% — 加载/空/错误/权限均覆盖，缺"成功 toast 与角标 +1 的精确同步策略"

### 6.2 优化建议

- **[建议] 加车成功反馈位置**：当前 toast 居中可能遮挡商品。改为底部抬起 56px（避开 TabBar），原因 → 不遮挡浏览主体；预期 → 提升一屏多次加车的流畅感。
- **[建议] 骨架屏闪烁频率**：1500ms 循环偏快，建议 2000ms，原因 → 减少视觉疲劳；预期 → 改善慢网用户感知。
- **[建议] 排序 chip 增加滑动指示器**：当前可横向滚动但无视觉提示。在右侧加渐变 mask，原因 → 暗示可滑动；预期 → 用户发现率提升。
- **[建议] 加车按钮触摸目标扩大**：当前 ⊕ 仅 24×24 视觉，触摸 hit-area 应扩到 ≥48×48，原因 → 符合 a11y 最低线；预期 → 误触率下降。

### 6.3 技术注意事项

- 瀑布流渲染 >100 项时启用虚拟滚动（react-window / vue-virtual-scroller）
- 商品图懒加载 + LQIP 占位（避免下拉过快时空白）
- 滚动节流 16ms (rAF)
- 筛选 sheet 打开时锁定 body scroll
- prefers-reduced-motion 时关闭所有 spring / scale 动画
