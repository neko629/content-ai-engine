演示说明

  • 多模型网关：候选按用途配置，逐个尝试、失败自动 fallback（mock 兜底）。
  • 标题：改写 → 强清洗污染/拒答检测 → 降温度重试。
  • 封面：标题 → LLM 扩写 SD 提示词(带缓存) → 文生图 → 完成回写。

  • 结构化输出：脏 JSON → 容错解析 → 结构校验 → 带错误反馈重试。
